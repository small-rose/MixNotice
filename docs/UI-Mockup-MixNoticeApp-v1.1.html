扩展机制：组件代码只引用语义 token（bg / surface / primary / text…），一套主题即一份 JSON 文件（.mtheme，schemaVersion 向后兼容）——新增主题零代码改动；用户可在任一主题上叠加自定义强调色与冷暖基调（色相 ±8°），对比度不足时自动校正；自定义主题 V1.1 随账号跨端同步，V2.0 可随声景卡片分享。

{ "schemaVersion": 1, "id": "night-forest", "name": "夜林", "mode": "dark", "colors": { "bg": "#0F1512", "surface": "#1A241E", "surface2": "#223029", "primary": "#4CAF87", "primaryPress": "#3D9B72", "amber": "#E8A854", "text": "#EAF2EC", "textSub": "#9DB3A6", "danger": "#E2695E", "line": "#EAF2EC14" } }

五、v1.1 设计说明

① 移动端双主题补全：深色覆盖 声音库/混音台/睡眠/休息，浅色覆盖 声音库/方案库/外观设置；结构完全同构仅换 token，模式色区分（睡眠=琥珀、休息=teal）在两套主题下均保持语义一致。

② 桌面端底部播放条：与开源音乐工具一致的三段式——左侧方案信息（支持拖入音源）、中间倒计时 chip + 主按钮、右侧总音量与主题切换；播放条 h88 常驻，解决 v1.0「控制入口分散」的问题；侧边栏可折叠至 72。

③ 主题可扩展可自定义：三层 Token 架构（组件引用语义 token → 主题 JSON 覆盖 → 用户叠加微调）；4 套内置（夜林/深空/晨雾/暖沙）；对比度守卫保证任何自定义结果可读；.mtheme 导入导出为后续主题分享铺路。

④ 待办：音源图标为 emoji 占位，正式版替换为 1.8pt 描边原创线性图标；设置页仅展示「外观」分组，其余分组（播放/桌面专属/关于）结构相同。
