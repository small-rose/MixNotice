## 二、背景与目标

### 2.1 背景
用户在入睡、专注、休息三个高频场景需要可自由组合的自然氛围声。现有产品在桌面端体验、中文场景化、双端一致性上存在缺口。V1.0 以「多轨混音 + 双计时器 + 后台播放」构建最小价值闭环，双端同步上线。

### 2.2 要解决的问题
- 声音单一易腻 → 多轨自由混音与方案保存。
- 息屏/切后台播放中断 → 双端后台续播能力。
- 无人化的入睡/休息计时 → 睡眠渐弱倒计时与休息提醒倒计时。

### 2.3 成功指标与口径（上线后 30 天自然周期）
| 指标 | 目标值（估算） | 口径 |
|------|----------------|------|
| 次日留存 | ≥ 35% | 新增设备次日启动 App 的比例（V1.0 免登录，以匿名设备号为单位） |
| 人均单日使用时长 | ≥ 25 分钟 | 匿名统计的前台+后台播放累计时长 / 活跃设备数 |
| 混音方案保存率 | ≥ 40% | 累计启动 ≥3 次的设备中，保存过 ≥1 个自定义方案的比例 |
| 睡眠倒计时使用占比 | ≥ 50% | 携带倒计时启动的播放会话数 / 总播放会话数 |
| 崩溃率 | ≤ 0.3% | 崩溃会话数 / 总会话数 |

## 三、名词与术语定义

| 术语 | 定义 |
|------|------|
| 音源（Track Source） | 一个可循环播放的自然/氛围声音素材（如「小雨」），App 内最小声音单位 |
| 音轨（Channel） | 混音台中一个正在参与混音的音源实例，含独立音量与静音状态 |
| 混音（Mix） | 若干音轨的集合（音源 + 各自音量），构成一个声景 |
| 方案（Preset） | 已保存的混音配置；分「预设方案」（出厂自带）与「自定义方案」（用户保存） |
| 睡眠倒计时 | 播放 N 分钟后音量渐弱并停止播放的计时器 |
| 休息倒计时 | 播放 N 分钟后以渐强提示音提醒用户回归的计时器（结束不强制停止播放） |
| 播放会话 | 从用户点击播放到停止/渐弱结束之间的一次连续使用 |

## 五、方案对比与选型说明

### 5.1 跨端技术方案
| 维度 | A. Flutter 单代码库（推荐） | B. RN + Electron | C. 各端原生 |
|------|------------------------------|-------------------|--------------|
| 实现成本 | 中（一套 UI/逻辑） | 高（两套 UI） | 最高（三套） |
| 双端一致性 | 最高 | 中 | 低 |
| 平台适配风险 | 托盘/后台播放插件成熟度待 PoC | 各自生态成熟 | 低 |
| 后续商业化（V1.1 跨端同步/内购） | 一套逻辑共享 | 逻辑易漂移 | 三份实现 |
| 演进路径 | 本期 → V1.1 直接扩展账号/订阅模块 | 需双端各写一遍 | 不具备演进性价比 |

**选型结论**：A。PoC（W1-W2）验证桌面托盘与安卓息屏两项；若桌面端插件不成熟，兜底方案为桌面端切 Electron（UI 层重写，业务逻辑层用共享 Dart→JS 移植或独立实现，成本已预留）。

### 5.2 音频方案
- 音源预处理为 30-60s 无缝循环 AAC（128kbps 估算，单曲 ≤1MB），循环对齐 + 首尾交叉淡化，出厂前过听感验收。
- 多轨播放：多播放实例叠加 + 实例级音量；渐弱/渐强由应用层定时器按帧调音量实现（不依赖系统 API，保证双端一致）。

| 作为助眠用户，我想要三轨混音 + 30 分钟渐弱入睡 | 睡前床上，手机息屏 | FR-04~09, 14~17, 21~22 |

## 七、功能需求

> 状态词约定：必须（shall）/ 应该（should）/ 可以（may）/ 禁止（must not）。每条需求含 Given/When/Then 验收标准。

### 7.1 音源库
**FR-01 音源浏览**：声音库首页必须按「自然 / 噪音 / 生活」三组展示 16 个内置音源（雨·小雨、雨·大雨、雷声、风、溪流、海浪、鸟鸣、篝火、森林、夜晚虫鸣、白噪音、粉噪音、棕噪音、咖啡馆、键盘敲击、风铃）。每个音源必须展示名称与图标。音源文件必须全内置在安装包内（总体积 ≤ 30MB，估算）。
- Given 用户进入声音库，When 页面加载完成，Then 三组音源全部展示且无缺失。
- Given 离线状态，When 打开声音库，Then 全部音源正常展示与使用（纯本地能力）。

**FR-02 试听**：点击任一音源必须以默认音量（50%）播放该音源循环；再点击必须停止试听。试听禁止影响当前混音中已存在的同源音轨。
- Given 混音中已有「海浪」音轨，When 用户点击声音库中的「海浪」试听，Then 仅播放试听声，原音轨音量与状态不变。

**FR-03 加入混音**：点击音源卡片上的「加入混音」必须把该音源以默认音量 50% 加入当前混音并立即开始播放（若播放器处于空闲则自动开始播放）。
- Given 当前混音已有 6 轨，When 点击「加入混音」，Then 必须弹窗提示「最多 6 轨，请先移除一条音轨」，不加入。

### 7.2 混音台
**FR-04 音轨展示**：混音台必须按加入顺序展示音轨卡片，每张卡片必须含：音源名、图标、音量滑杆（0-100）、静音开关、移除按钮。
**FR-05 独立音量**：拖动某音轨滑杆必须实时（≤200ms 延迟，估算）改变该轨音量且不影响其他音轨。
**FR-06 单轨静音**：开启某轨静音必须立即静默该轨并保留其音量值；取消静音必须恢复原音量。
**FR-07 移除音轨**：点击移除必须立即停止该轨播放并从混音中删除；剩余音轨播放不受影响。
**FR-08 音轨上限**：同时播放音轨数禁止超过 6。
**FR-09 总音量**：总音量必须独立于各轨音量，作用于最终混音输出；总音量为 0 时禁止停止播放（保持播放状态，恢复音量即出声）。

### 7.3 方案管理（本地）
**FR-10 预设方案**：出厂必须内置 8 个预设方案（雨天篝火、森林晨间、海边夜晚、雨夜雷声、溪流清晨、白噪音专注、咖啡馆午后、虫鸣夏夜），每个方案必须可一键载入（替换当前混音并播放）。
- Given 预设方案包含「白噪音 + 雨声」两轨，When 用户一键载入，Then 混音台出现对应 2 轨且音量与预设一致并开始播放。

**FR-11 保存自定义方案**：用户必须可以把当前混音（音源集合与各轨音量）保存为自定义方案，必须支持命名（默认名「我的方案 N」，N 为序号）；自定义方案必须持久化到本地存储，重启 App 后仍在。
**FR-12 方案编辑与删除**：自定义方案必须支持重命名与删除；删除必须二次确认。预设方案禁止修改与删除。
**FR-13 方案上限**：自定义方案数量禁止超过 20 个；达到上限时必须提示「方案已满，请删除后再保存」。
**FR-13a 方案数据迁移预留**：方案本地存储必须采用结构化 JSON 格式（含版本号字段），为 V1.1 云同步预留字段（本版本不实现同步）。

### 7.4 睡眠倒计时
**FR-14 模式与时长**：睡眠倒计时必须提供 15/30/45/60 分钟四档与自定义输入（1-480 分钟，整数）；启动倒计时时若播放器空闲，必须提示「当前未在播放，是否自动播放当前混音/选定方案」。
**FR-15 渐弱**：倒计时结束前 5 分钟（自定义时长 <6 分钟时改为结束前 1 分钟）必须开始线性渐弱至 0。
**FR-16 结束行为**：倒计时归零必须停止全部播放并进入空闲态；必须不发出任何提示音（助眠场景）。
**FR-17 取消与调整**：运行中必须可取消（播放继续）与更换时长（重新计时）；锁屏/息屏期间倒计时必须继续生效（依赖系统级定时而非 UI 计时器）。
- Given 启动 30 分钟睡眠倒计时后立即锁屏，When 30 分钟后，Then 播放已停止且音量渐弱发生在最后 5 分钟。

### 7.5 休息倒计时
**FR-18 时长与提醒**：休息倒计时必须提供 5/10/15/20 分钟四档与自定义输入（1-60 分钟）；归零时必须以渐强提示音（3 秒内从 20% 渐强至 80% 音量，估算值）提醒一次，随后自动恢复常规音量，禁止重复提醒。
**FR-19 联动方案**：启动休息倒计时必须可选「同时播放默认放松方案」（设置中可指定，默认为预设方案「溪流清晨」）；结束时禁止停止播放。
**FR-20 取消**：运行中必须可随时取消，取消不产生提示音。

### 7.6 后台播放与全局控制
**FR-21 移动端息屏续播**：Android 必须以前台服务方式保证息屏续播；iOS 必须启用后台音频模式。息屏后播放禁止中断（系统资源紧张被杀除外，见 12 异常清单）。
**FR-22 通知栏控制**：移动端后台播放时必须在通知栏/锁屏展示媒体控制（播放/暂停、当前方案名），操作结果与前台状态一致。
**FR-23 桌面托盘**：桌面端必须支持关闭主窗口后常驻系统托盘；托盘菜单必须含：播放/暂停、方案列表（最近 5 个方案）、退出。托盘操作必须与主窗口状态实时同步。
- Given 桌面端播放中点击托盘「暂停」，When 重新打开主窗口，Then 界面显示为暂停态。

### 7.7 设置
**FR-24 音质**：必须提供「标准/高质量」两档（对应 96/128kbps 素材版本，估算），默认高质量；切换后下次播放生效。
**FR-25 默认方案**：必须可设置 App 启动时的默认方案（默认不自动播放）。
**FR-26 开机自启**（仅桌面端）：应该提供开机自启开关，默认关闭。
**FR-27 关于与授权**：必须提供「关于」页，含版本号、开源许可、音频素材授权清单（素材名—来源—授权类型）。

### 7.8 数据与预热
**FR-28 匿名埋点**：必须按第十章定义上报匿名事件；禁止采集姓名、手机号、位置、通讯录等个人信息；上报必须可被系统级网络异常容忍（失败静默丢弃或下次补报，禁止阻塞功能）。
**FR-29 体验次数预热展示**（Should）：会员入口占位处应该展示「V1.1 敬请期待」及免费体验机制说明文案；本版本禁止出现任何付费/解锁行为。

## 九、业务流程与状态流转

### 9.1 播放器状态机
```
状态：idle（空闲）/ playing（播放中）/ paused（暂停）
事件与迁移：
- idle --[载入方案/加入音轨并播放]--> playing
- playing --[暂停/通知栏暂停/托盘暂停]--> paused
- paused --[恢复]--> playing
- playing/paused --[清空混音/睡眠倒计时归零]--> idle
约束：状态单向，禁止 paused --> idle 的隐性迁移（仅显式清空触发）；恢复播放必须校验混音非空。
```

### 9.2 倒计时状态机（睡眠与休息共用骨架）
```
状态：idle / running（运行中）/ fading（渐弱中，仅睡眠）/ finished / cancelled
事件：start / cancel / tick(归零) / 修改时长
- idle --[start]--> running
- running --[剩余=5min(睡眠)]--> fading
- fading --[归零]--> finished --> idle（睡眠：停止播放；休息：播提示音后 running 行为终止）
- running/fading --[cancel]--> cancelled --> idle（播放状态保持不变）
约束：倒计时计时必须基于系统墙钟（绝对到期时间点），锁屏/休眠唤醒后必须按真实时间校正；同一时刻禁止同时运行两个倒计时（启动新倒计时必须先提示替换或取消旧倒计时）。
```

### 9.3 核心任务流
```
选声音（声音库）→ 加入混音（自动播放）→ 调音量（混音台）→ [可选] 保存方案
                                                              ↓
                            设倒计时（睡眠/休息）→ 播放/息屏离开 → 到点结束/提醒
```

## 十、数据与埋点需求

| 事件名 | 触发时机 | 属性 |
|--------|----------|------|
| app_launch | App 启动 | 平台、版本、首次启动与否 |
| session_play_start | 播放会话开始 | 音轨数、是否来自预设方案 |
| track_add | 音源加入混音 | 音源 ID、当前音轨数 |
| mix_save | 保存自定义方案 | 音轨数、是否含重复音源 |
| preset_use | 载入预设方案 | 方案 ID |
| timer_start | 启动倒计时 | 类型（sleep/rest）、时长档位、是否联动方案 |
| session_play_end | 播放会话结束 | 持续时长（秒）、结束方式（手动/睡眠渐弱） |
| custom_duration_used | 使用自定义时长 | 类型、输入值 |

- 指标口径：留存 = 首次启动后第 N 日再次启动的设备占比；会话 = 一次 play_start 到 play_end；方案保存率分母 = 启动 ≥3 次设备。
- 数据去向：匿名聚合上报，V1.0 不做用户级明细存储。

## 十一、权限与安全要求

| 项 | 要求 |
|----|------|
| 移动端权限 | 仅申请通知权限（Android 13+ 前台服务通知；iOS 本地通知可选）。禁止申请存储、通讯录、位置、麦克风 |
| 通知权限拒绝 | 拒绝后前台服务仍运行（Android 显示静默通知），功能可用性不受影响，仅控制入口降级为 App 内 |
| 网络 | 仅用于匿名埋点上报（可失败）；音源、方案、计时全部本地，断网全功能可用 |
| 数据安全 | 方案数据仅存本地沙箱；删除 App 即全部清除，必须在设置页明示「数据仅保存在本机」 |
| 内容安全 | 音源均为自然/环境声，无歌词、无语音内容；授权清单随包公示 |

## 十二、异常处理清单

| 编号 | 异常场景 | 处理 |
|------|----------|------|
| E-01 | 空混音时启动倒计时 | 提示「当前未在播放」，提供「自动播放默认方案/取消」选择 |
| E-02 | 音频文件缺失/损坏（包体异常） | 该轨跳过播放，混音台标记「暂不可用」，其余轨正常；上报异常事件 |
| E-03 | 移动端被来电/其他应用抢占音频焦点 | 暂停播放，通话结束自动恢复（Android）；iOS 遵循系统中断策略 |
| E-04 | 息屏播放被系统杀死 | 下次启动恢复上次混音与方案（不自动播放）；设置页提供「电池优化白名单」引导（Android） |
| E-05 | 本地存储写入失败/存储满 | 保存方案时提示「保存失败，请检查存储空间」，不产生半写数据 |
| E-06 | 方案数据损坏（版本不识别） | 丢弃损坏条目并提示「部分方案无法读取已跳过」，不影响其余数据 |
| E-07 | 埋点上报失败 | 静默失败，最多缓存 20 条下次补报，禁止任何用户感知与阻塞 |
| E-08 | 同时启动两个倒计时 | 弹窗「已有计时进行中」：替换（取消旧启动新）/ 取消 |
| E-09 | 音频焦点反复抢占（异常循环） | 3 次内恢复重试，超过则保持暂停并仅在用户手动操作时恢复，防止耗电 |
| E-10 | 蓝牙耳机断开 | 暂停播放（移动端系统默认行为），不自动恢复 |
| E-11 | 自定义时长输入非法（超范围/非整数） | 输入框标红并提示允许范围，禁止提交 |
| E-12 | 桌面端托盘图标加载失败 | 降级为默认图标，托盘菜单功能不受影响 |
