# MixNoticeApp UI 设计规范 v1.1

> 变更记录：v1.0 初版；v1.1 —— ①移动端双主题覆盖全部页面；②桌面端改为「底部固定播放条」布局（参考开源音乐工具成熟范式）；③新增第八章「主题体系」：Token 架构 + 内置主题 + 用户自定义 + 扩展机制。
> 设计原则不变：沉浸、安静、少打扰。

## 一、设计目标与用户
| 用户 | 视觉诉求 | 设计响应 |
|------|----------|----------|
| 助眠族（夜间床上） | 暗、柔、不刺眼 | 默认深色「夜林」，无纯白大面积，动效缓慢 |
| 专注族（桌面常驻） | 低调、不抢注意力 | 桌面端低饱和 + 底部固定播放条，工作区稳定 |
| 休息族（日间间隙） | 清爽、有自然感 | 浅色「晨雾」暖纸底 |
| 个性化用户 | 想要自己的样子 | 主题可自定义强调色/冷暖基调，可导入导出分享 |

## 二、配色

### 2.1 内置主题（v1.1 起为 4 套：2 深 + 2 浅）
| 主题 | 模式 | bg / surface | primary | 强调 | 适用 |
|------|------|--------------|---------|------|------|
| 夜林（默认） | 深 | #0F1512 / #1A241E | #4CAF87 | 琥珀 #E8A854 | 夜间助眠、绿色自然感 |
| 深空 | 深 | #0D1117 / #161D27 | #5B9BD5 | 琥珀 #E8A854 | 偏好冷色调的用户 |
| 晨雾 | 浅 | #F5F4EF / #FFFFFF | #2E7D5C | #C77E2E | 日间、暖纸质感 |
| 暖沙 | 浅 | #F7F2E9 / #FFFFFF | #B0713A | #B0713A | 日间、暖木质感 |

### 2.2 深色「夜林」完整 Token（其余主题同结构仅换值）
| Token | 值 | 用途 | 理由 |
|-------|-----|------|------|
| bg | #0F1512 | 页面底 | 近黑带绿相，夜里不刺眼 |
| surface | #1A241E | 卡片/列表底 | 与 bg 层次清晰不刺眼 |
| surface-2 | #223029 | 次级卡片/轨道 | 两级层次足够 |
| primary | #4CAF87 | 主操作/播放态/滑杆填充 | 与 surface 对比 4.6:1（AA） |
| primary-press | #3D9B72 | 按压态 | 亮度 -8% |
| amber | #E8A854 | 时间/火元素强调 | 占比 ≤5%，形成场景记忆 |
| text | #EAF2EC | 主文字 | 对比 13.8:1（AAA） |
| text-sub | #9DB3A6 | 次要文字 | 对比 4.7:1（AA） |
| danger | #E2695E | 删除/错误 | 低饱和红，仅破坏性操作 |
| line | rgba(234,242,236,.08) | 分隔线 | 柔和不切割 |

浅色映射规则：bg/surface 提亮、primary/text 加深至同对比度档位（≥4.5:1）；amber 加深为 #C77E2E；两主题组件结构完全一致，仅换 token。

## 三、字体与排版
- 字族：`-apple-system, "PingFang SC", "HarmonyOS Sans", "Microsoft YaHei", sans-serif`。
- 字阶（移动 / 桌面 +2）：display 56/64·300（倒计时大数字）；title 22/30·600；head 17/24·600；body 15/22·400；caption 13/18·400。
- 数字一律 `tabular-nums` 等宽防跳动。

## 四、间距与形状
- 间距：4 的倍数（4/8/12/16/20/24/32）；页面左右边距 20，卡片内边距 16，卡片间距 12。
- 圆角：卡片 16 / 按钮 12 / 图标 24 / 迷你播放条顶 20 / 桌面底部播放条顶 16。
- 触控目标 ≥44pt；滑杆轨道视觉 4pt + 热区 44pt。
- 动效：250ms（微交互）/ 400ms（转场），曲线 `cubic-bezier(0.22,1,0.36,1)`；倒计时环禁止跳动；主题切换 300ms 全局颜色过渡。

### 5.8 桌面底部固定播放条（v1.1 新增）
| 属性 | 值 |
|------|-----|
| 位置 | 固定于主窗口底部，高 88，全宽；内容区在其下方滚动，不被遮挡 |
| 左区（280 固定） | 方案封面 56（同色系平涂）+ 方案名 head（单行截断）+ 音轨摘要 caption（「3 轨 · 播放中」） |
| 中区（居中弹性） | 播放/暂停主按钮 52（primary 圆底）+ 睡眠倒计时 chip（剩余时间，点击跳计时器，无倒计时时隐藏）+ 混音台快捷图标 |
| 右区（280 固定） | 总音量滑杆（宽 160，amber 填充）+ 主题切换图标按钮 |
| 状态 | 播放中（▶→⏸）/ 暂停（封面降饱和 30%）/ 空闲无混音（整条隐藏，内容区占满） |
| 拖拽 | 音源卡可拖到左侧封面区 = 加入混音 |

### 5.9 主题设置组件（v1.1 新增）
| 组件 | 规格 |
|------|------|
| 主题卡 | 桌面 4 列 / 移动 2 列，每卡 120×88：上半为该主题 bg+primary 双色缩略平涂，下半主题名；选中态 primary 描边 2 + 右上 ✓ |
| 强调色选择 | 圆形色板 8 色（雨蓝/森绿/琥珀/陶土/雾紫/湖水/炭灰/樱粉），直径 32，选中外环 2；「＋」自定义唤起 hue 滑杆 |
| 冷暖基调滑杆 | 「冷 ↔ 暖」，仅微调 bg/surface 色相 ±8°，文字色自动反算保对比 |
| 实时预览 | 调整即时应用当前页（所见即所得），保留缩略对照 |

### 5.10 休息倒计时页（v1.1 补全）
- 与睡眠倒计时同构；进度环与「休息」标签用 teal #4CB8A4（深）/ #2E8C7A（浅），与睡眠 amber 形成模式色区分；说明文案「到点轻声提醒，不停止播放」。

## 六、桌面端布局（v1.1 重设计）
```
┌───────────┬──────────────────────────────────┐
│ 侧边栏     │        内容区（滚动）              │
│ 200 宽     │   声音库网格 / 混音台 / 方案库      │
│ 可折叠至72  │   最大内容宽 880 居中              │
├───────────┴──────────────────────────────────┤
│ 底部播放条 h88：封面方案 │ ▶+倒计时 │ 总音量+主题 │
└──────────────────────────────────────────────┘
```
- 「侧边导航 + 滚动内容 + 底部常驻播放条」三段式（与主流开源音乐工具布局范式一致）；播放条任何页面可见，桌面核心操作路径不中断。
- 侧边栏项：声音库、混音台、方案库、计时器、主题、设置（底部）；折叠态 72 宽仅图标。
- ≥1024 时计时器与混音台可 3:2 分栏同屏；<1024 单列；窗口 <560 提示最小尺寸（托盘仍可用）。

## 七、图标与插画、可访问性
- 沿用 v1.0：1.8pt 描边线性图标、音源 8 色淡底、语义化读屏、尊重减弱动态。
- 补充：自定义强调色不满足 4.5:1 时自动加深并提示「已自动调整以保证可读」，禁止不可读主题生效。

## 八、主题体系（v1.1 核心新增）

### 8.1 Token 三层架构
```
L1 基础层：组件代码只引用语义 token（bg/surface/primary/…），禁止写死色值
L2 主题层：一套主题 = 一份 JSON（只覆盖语义 token），内置 4 套随包分发
L3 用户层：在任一内置主题上叠加「自定义强调色 / 冷暖基调」，生成用户主题，本地保存
```
收益：新增主题零代码改动；换肤不动组件逻辑；主题文件天然跨端通用。

### 8.2 主题文件格式（.mtheme，schemaVersion 向后兼容）
```json
{
  "schemaVersion": 1,
  "id": "night-forest",
  "name": "夜林",
  "mode": "dark",
  "colors": {
    "bg": "#0F1512", "surface": "#1A241E", "surface2": "#223029",
    "primary": "#4CAF87", "primaryPress": "#3D9B72",
    "amber": "#E8A854", "text": "#EAF2EC", "textSub": "#9DB3A6",
    "danger": "#E2695E", "line": "#EAF2EC14"
  }
}
```

### 8.3 扩展与自定义规则
| 规则 | 说明 |
|------|------|
| 校验 | 导入校验 schemaVersion 与色值格式；缺省 token 回落基准主题（不白屏） |
| 对比度守卫 | primary/text 类 token <4.5:1 时自动微调并提示，禁止不可读主题生效 |
| 模式联动 | mode 决定图标/系统栏行为；「跟随系统」开关优先于手动选择 |
| 同步预留 | 自定义主题纳入 V1.1 云同步范围（随账号跨端） |
| 分享路径（V2.0） | 声景卡片可携带主题，试听即预览，确认后才保存 |

### 8.4 设置页信息架构
- 外观：主题选择 / 强调色 / 冷暖基调 / 跟随系统开关
- 播放：音质 / 默认方案
- 桌面专属：开机自启 / 关闭最小化到托盘
- 关于：版本 / 开源许可 / 音源授权清单 / 「数据仅保存在本机」说明
