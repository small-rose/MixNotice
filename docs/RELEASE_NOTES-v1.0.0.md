# MixNotice v1.0.0 — 首个正式版

> 发布日期：2026-10-27 · 包体：arm64 ≈ 36 MB（release 压缩后）· 最低支持 Android 5.0（API 21）

MixNotice 是一款注重隐私的自然声音混音 App：真实采集的雨声、风声、篝火与虫鸣，自由叠加成属于你的环境声。**无账号、无广告、无埋点**——所有数据只存在你的设备里。

## ✨ 功能亮点

### 🎚️ 多轨混音台
- 最多 **6 轨**同时播放，每轨独立音量与静音
- 总音量一键调节；音轨卡片支持快速移除
- 声音库勾选即添加 / 取消，试听按钮即点即听

### 🌙 睡眠 / 休息双倒计时
- 睡眠模式：5–480 分钟，结束前 5 分钟音量渐弱至停止
- 休息模式：反向渐强，温和提醒你回去干活
- 环形进度可视，基于系统墙钟，**不漂移**

### 🎵 后台稳定播放
- Android 前台服务 + 系统媒体通知（MediaStyle）
- 息屏、锁屏、切后台都能播放与控制
- WAKE_LOCK + `foregroundServiceType="mediaPlayback"`，符合 Android 13+ 规范（POST_NOTIFICATIONS 运行时申请）

### 🎨 四套内置主题 + 自定义强调色
- 晨雾（浅）、暖沙（浅）、夜林（深）、深空（深），默认晨雾
- 8 色强调色任选，主题文件支持导入导出（`.mtheme`）
- 深浅色跟随系统，状态栏图标明暗自动同步
- Logo 矢量自绘，随主题强调色自动变色

### 💾 100% 本地，隐私优先
- 无账号体系、无埋点上报、无第三方 SDK
- 方案 / 主题 / 设置全部存本机，卸载即无痕
- 全部 23 个音源打包在 APK 内，**离线可用**
