# MixNotice v1.1.0 更新说明

发布日期：2026-11-19

## 新增

- **田园音源扩充（4 → 8）**：新增「公鸡」「母鸡」「牛哞」「羊咩」「猫叫」5 个动物音源；原「鸡叫」拆分为公鸡 / 母鸡两个独立音源，「鸭叫」下线
- **声音库卡片副行文案**：每个音源卡片显示一句话描述（如「柴火噼啪燃烧」「磅礴大雨倾泻」），默认态可见
- **新增音源「NEW」徽标**：声音库中牛哞 / 羊咩 / 猫叫等新音源卡片带 amber「新增」标记
- **声音库分组与排序优化**：按「家禽 → 家畜 → 其他 → 环境」重新排序，分类更直觉
- **动物音源专属图标**：为新增音源绘制对应 glyph 图标

## 优化

- **音效素材整体重制**：狗叫、鹅叫、大/小雨等素材替换为更长时长、更高品质版本；动物叫声全部带垫底噪，消除突兀感
- **旧版本兼容映射**：v1.0.0 的自定义预设 / 已保存音轨中下线音源（chicken、duck-quack、frog）自动映射到新音源（母鸡 / 池塘），避免恢复旧配置时播放错音
- **声音库页面重构**：布局、状态管理（默认 / 播放 / 已加入 / 试听）与测试同步更新
