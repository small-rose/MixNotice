# MixNotice v1.1.0 — 田园音源扩充与声音库改版

> 发布日期：2026-11-19 · 包体：arm64 ≈ 47 MB（release 压缩后）· 最低支持 Android 5.0（API 21）

MixNotice 是一款注重隐私的自然声音混音 App：真实采集的雨声、风声、篝火与虫鸣，自由叠加成属于你的环境声。**无账号、无广告、无埋点**——所有数据只存在你的设备里。

本次更新聚焦「田园声场」：动物音源从 4 种扩到 8 种，音效素材整体重制，声音库页面同步改版。

## ✨ 功能亮点

### 🚜 田园音源 4 → 8
- 新增 **公鸡、母鸡、牛哞、羊咩、猫叫** 5 个动物音源
- 原「鸡叫」拆分为公鸡 / 母鸡两个独立音源，晨鸣与下蛋各是各的
- 「鸭叫」素材下线，环境水声由「池塘」承接
- 动物叫声统一带垫底噪，消除音源间的突兀落差

### 🎨 声音库页面改版
- 每个音源卡片新增**一句话副行文案**（如「柴火噼啪燃烧」「磅礴大雨倾泻」）
- 新音源卡片带 amber「新增」徽标，一眼找到新东西
- 分组按「家禽 → 家畜 → 其他 → 环境」重新排序，更符合直觉
- 为新增音源绘制专属 1.8pt 线性图标

### 🔧 旧配置无缝兼容
- v1.0.0 的自定义预设 / 已保存音轨中，下线音源 ID 自动映射：`chicken` → 母鸡，`duck-quack` / `frog` → 池塘
- 恢复旧方案不会播放错音，无需手动调整

### 🔉 素材整体重制
- 狗叫、鹅叫、大 / 小雨替换为更长时长、更高品质的版本
- 全部音源保持响度归一化（loudnorm）与 1s 交叉淡化无缝循环

## 🌿 声音库（27 个真实音源 · 4 分组）

| 分组 | 音源 |
|---|---|
| 自然（13） | 小雨、大雨、雷声、风、溪流、海浪、鸟鸣、杜鹃、麻雀、夜莺、篝火、森林、夜晚虫鸣 |
| 田园（8） | 公鸡、母鸡、狗叫、鹅叫、牛哞、羊咩、猫叫、池塘 |
| 噪音（3） | 白噪音、粉噪音、棕噪音 |
| 生活（3） | 咖啡馆、键盘敲击、风铃 |

内置 8 组方案：雨天篝火 / 森林晨间 / 海边夜晚 / 雨夜雷声 / 溪流清晨 / 白噪音专注 / 咖啡馆午后 / 虫鸣夏夜。

所有音源均为真实录音（非合成），来自 Wikimedia Commons 等平台的 CC 授权素材，经响度归一化与无缝循环处理，逐条授权见 [`docs/音频素材授权清单.csv`](../docs/音频素材授权清单.csv)。
