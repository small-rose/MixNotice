# 枕声 SoughMix v1.2.0 — 全新品牌、播放器卡片与 11 组内置方案

> 发布日期：2026-11-21 · 三个架构包（arm64 / armv7 / x64）· 最低支持 Android 5.0（API 21）

枕声 SoughMix 是一款注重隐私的自然声音混音 App：真实采集的雨声、风声、篝火与虫鸣，自由叠加成属于你的环境声。**无账号、无广告、无埋点**——所有数据只存在你的设备里。

v1.2.0 是一次大版本更新：完成品牌升级（MixNotice → 枕声 SoughMix）、重做后台播放控制台、扩充内置方案至 11 组，并修复了计时器环形进度等一系列体验问题。

## ✨ 功能亮点

### 🎬 播放器式后台控制台（重做）
- 下拉通知栏与锁屏出现标准**媒体播放器卡片**，显示当前混音方案名、音轨数、睡眠/休息倒计时剩余时间
- 卡片支持三键控制：**上一首 · 播放/暂停 · 下一首**；上一首/下一首在方案库中**循环切换**（内置 11 组 + 自定义方案）
- 倒计时开启后，副标题与播放器进度条**每秒实时刷新**（如 `雨天篝火 · 2 轨 · 睡眠 12:34`）
- 采用 Native 自建 MediaSession + MediaStyle 通知，替代原 `audio_service` 通知链路，修复了此前控制台消失、暂停后无法操控的问题
- 状态栏小图标改为全透明剪影，消除主图右下角重复的第二个 logo

### 🎨 全新品牌「枕声 SoughMix」
- 中文名 **枕声**、英文名 **SoughMix**，与应用内标识、官网、文档全面统一
- 包名由 `com.mixnotice.mixnotice` 改为 `com.soughmix.app`，通知通道 ID 同步统一
- 应用内 Logo 与桌面图标资源全套重绘，品牌色为主色森绿 + 暖琥珀

### 📱 双桌面图标（浅色 / 深色 / 跟随系统）
- 设置页「品牌」区新增「桌面图标」选项，可在浅色、深色、跟随系统之间一键切换
- 浅色图标为全新绘制的自适应图标（Adaptive Icon），适配浅色壁纸与桌面主题
- 「App 内标记」与「手机桌面图标」拆分为两个独立设置，互不影响
- 注：部分安卓启动器在切换图标后，图标会短暂消失或重新出现在桌面末屏，属系统正常行为

### 🧩 内置方案 8 → 11 组
- 调整 3 组：森林晨间（+夜莺）、虫鸣夏夜（+池塘）、咖啡馆午后（+键盘）
- 新增 3 组：**牧场黄昏**（牛哞/羊咩/风）、**农家清晨**（公鸡/母鸡/溪流）、**粉噪深眠**（粉噪/篝火）
- 田园组带垫噪动物音首次进入内置方案；狗叫/鹅叫/猫叫等突兀叫声保留在声音库供自定义

### ⏱️ 计时器与交互修复
- 修复点击倒计时后**环形进度不变化**的问题：改为显示剩余比例（满环 → 递减到空），并修复短弧被跳过的绘制 bug
- 睡眠启动默认方案改为**雨天篝火**，更贴合助眠场景
- 睡眠页强调色调整为更柔和的暖琥珀，贴合夜间氛围、与森绿主色更协调

### 🔢 版本与设置
- 设置页「版本」号改为从构建脚本生成的版本常量读取，升级只需改 `pubspec.yaml` 一处，不再漏改
- 声音库分组顺序调整为 **自然 → 田园 → 生活 → 噪音**，生活类音源前移

## 📥 安装说明

1. 下载对应架构的 APK
2. 首次安装需允许「安装未知来源应用」
3. **从旧版 MixNotice（com.mixnotice.mixnotice）升级时**：因包名变更，系统视作全新 App，请先卸载旧版再安装；如需保留方案/主题，请先在旧版导出（`.mtheme`）
4. 首次播放时会请求通知权限，请允许，以启用锁屏与下拉控制台；也可到设置页「通知栏控制」跳转系统设置开启
